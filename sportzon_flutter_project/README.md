# SPORTZON Flutter Web

A Flutter starter project containing the supplied SPORTZON `lib/main.dart`.

## Requirements
- Flutter SDK (stable)
- Chrome

## Run
Open this folder in VS Code, then run these commands in its terminal:

```bash
flutter pub get
flutter run -d chrome
```

## Build for web
```bash
flutter build web
```

## Note
This project includes the provided front-end Dart file. It does not include a backend server,
real authentication, payment processing, or verified live product inventory/prices.
